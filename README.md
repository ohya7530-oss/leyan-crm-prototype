## 使用方式

下載 `index.html`，以瀏覽器開啟。包含今日總覽、工作紀錄、客戶搜尋、工作報告與 LINE 範本五個頁面。僅供假資料與介面流程測試，請勿輸入真實客戶資料。

## 資料與安全限制

- 資料只保存在使用者當前瀏覽器的 localStorage，沒有後端資料庫或跨裝置同步；清除瀏覽器資料可能造成紀錄遺失。
- 原始 localStorage KEY 為 `leyan-customer-demo-v1`，未修改。
- 角色切換只是前端示範，不是真正登入或安全權限控管；不適合正式使用或真實客資。
- 未連接 Google Calendar、LINE、Telegram 或 AI 服務。LINE 範本只是可複製文字；分類與行事曆皆為測試示意。
- 工作報告只提供預覽與瀏覽器列印，未設定定時產生或自動傳送。
- 已知限制：工作報告目前未排除「個人紀錄」，管理者示範角色可看見所有前端紀錄。此處未套用任何既有報表 Bot 的修復。
- 內含原附件的示範種子資料；未加入既有 Bot、匯入資料庫、瀏覽器 localStorage 匯出或其他工作區內容。
